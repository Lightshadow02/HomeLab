# Portfolio

[← Retour au README](../README.md)

Tout ce qu'il faut pour présenter ce projet sur [hloureiro.fr](https://hloureiro.fr) :

| Fichier | Usage |
|---|---|
| [fiche-projet.md](fiche-projet.md) | Textes prêts à coller : titre, accroche, résumé court, description longue, chiffres, technologies, légendes |
| [homelab.json](homelab.json) | Les mêmes informations en données structurées, pour générer la carte projet automatiquement |
| [homelab.html](homelab.html) | Page autonome (sans dépendance externe), adaptée au mobile, à intégrer telle quelle ou à reprendre |
