Défense en profondeur

Périmètre

pfSense virtualisé, refus par défaut, IPS Snort en blocage sur le WAN, pfBlockerNG.

Segmentation

Cloud exposé isolé dans sa propre zone, stockage sur une interface physique dédiée.

Accès distant

VPN WireGuard ; consoles d'administration jamais exposées (reverse proxy TLS + listes d'accès).

DNS et TLS

DNS local split-horizon avec DNSSEC ; certificats Let's Encrypt ECDSA, wildcard par challenge DNS.

Supervision

Prometheus, Grafana et Loki ; alertes rédigées en français, envoyées sur téléphone.

Sauvegardes

Proxmox Backup Server : 2 copies, vérification hebdomadaire, restauration testée.
